Эмбеддинги

Сервер эмбеддингов в локальной сети (EmbeddingGemma, OpenAI-совместимый /v1/embeddings). Индекс строится по всей базе и пополняется по мере записи.

Telegram

Бот: публикации в каналы, ответы в группе и команды владельца из личных сообщений.

Выключено: бот не читает сообщения, не отвечает в группе, не выполняет команды и не публикует. Ожидающие посты и сообщения остаются, обработаются после включения.



      

        Бот и каналы
        

          
          

        

          

        

          

        

          

        

          

        

          

        

          
          
Бот читает сообщения группы. Чтобы видеть все сообщения, а не только команды и упоминания, отключите privacy mode в @BotFather (/setprivacy → Disable) и добавьте бота в группу заново.

      


      

        Размер сообщений
        
Telegram не умеет менять размер шрифта в сообщениях бота, поэтому задаётся длина одного сообщения. Заголовки, жирный, ссылки и код оформляются автоматически.

        

          
          
Длинный ответ разбивается на несколько сообщений.

        

          
          
Пост длиннее лимита не уйдёт: модель получит ошибку и сократит текст.

        

          

        

          
          
Ответ группы обрезается по границе предложения.

      


      

        Владелец и команды
        

          
          
Напишите боту в личку со своего аккаунта: пока ID не задан, бот ответит вашим ID. Сообщения с этого ID из личного чата с ботом выполняются как команды: у персоны brain полный набор инструментов (shell, http, память).

        

        

          
          
          
Команды и ответы попадают в историю этого пространства.

      


      

        Группа: автоответы
        

          
Новые сообщения классифицирует Jev. Если нужен ответ, пишет персона brain. Ответ идёт в группу через очередь, если режим группы «подтверждение».

        

          
          
Порог уверенности, что сообщение требует ответа. Выше — отвечает реже и только на явные запросы.

        

          

            
            
            
            
          

          
Спам не получает ответа никогда.

        

          

          
Без shell и http. Активные пользовательские функции тоже появятся здесь.

        

          

          
Пространство самой группы (telegram-group) включено всегда. Личное пространство владельца сюда не добавляйте, если не хотите, чтобы группа его видела.

Настройки

      
Адрес API оркестратора. По умолчанию — тот же хост, с которого открыта страница.

      

        

          
          
        

        
        
      

      


      
Секреты основной персоны (логины, токены)
      
Ассистент подставляет значение как {{secret:имя}} в http-запрос. Само значение он не видит и в ответах оно маскируется. Здесь видны только имена.

      

        

        

        
      

      

      


      


      
LLM-провайдер

      
Куда оркестратор отправляет запросы к модели — свой vLMM-сервер, OpenRouter или любой другой OpenAI-совместимый endpoint. Изменения применяются сразу, без перезапуска сервера.

Продвинутые параметры
        
Для опытных пользователей — дополнительные настройки поведения модели.

        

          

            
            
            
Размер контекстного окна модели. Обычно определяется автоматически.

          

          

            
            
            
Максимум циклов «план → выполнение пула → анализ». Внутри одного пула все независимые функции выполняются до следующего обращения к модели.

          

          

            
            
            
При каком проценте занятости KV-кеша (или контекстного окна для облачных бэкендов) запускать автоматическое сжатие дерева памяти.

          

          

            
            
            
Рассматривает только top K наиболее вероятных токенов при выборе следующего.

          

          

            
            
            
Штраф за повторение похожих токенов, которые уже были.

          

          

            
            
            
Штраф за появление новых токенов, которые ещё не были в ответе.

          

        


      

      
Ризонинг (thinking tokens)
        
Для моделей вроде openai/gpt-oss-120b на OpenRouter — запрашивает и показывает в чате цепочку рассуждений модели перед финальным ответом. Игнорируется провайдерами/моделями, которые этого не поддерживают.

        

          

            
            
Можно также переключать прямо в чате — этот флажок задаёт значение по умолчанию.

          

          

            
            
          

        

      

      
Проверка ответа (Jev)
        

          

            
            
Jev решает «прошло / не прошло» по существу и языку. Если уверен, LLM-проверка пропускается. Если не уверен, проверяет LLM. Текст сообщений уходит в OpenRouter.
